# Podcast Reader v2.0.0 发布说明

v2.0.0 的主题是：**从“功能完整”升级为“结果可信、恢复可靠、分享安全、真正闭环”。**

## 用户最能感知的变化

- 中断后不会静默漏内容：来源指纹、切块设置、序号和总时长覆盖全部验证，损坏缓存自动隔离重建。
- 不再假成功：需要选择节目、仍为 partial 或等待能力时返回 action-required，而不是成功退出。
- Doctor 不再把 `uv` 等同于“已安装”：明确区分离线就绪和首次运行仍需联网下载。
- 分析不再停在 `ready_for_analysis`：Skill 要求当前 Agent 完成报告、结构化证据、严格校验和阅读器。
- 引文必须真的是原话：伪时间戳、错误枚举、缺失 segment、越界章节和重构短引都会被拒绝。
- 长任务可观察：分块百分比、已完成数量、耗时、ETA 和部分 transcript 持久化。
- 多语言与说话人能力不再靠文案：任意目标语言有逐段覆盖契约；说话人时间段可从任意已配置能力回填。
- 默认分享安全：本机路径与敏感 URL 参数净化，完整逐字稿默认不进入分享包。
- 自动生成 `reader.html`：全文搜索、键盘焦点、移动端布局、屏幕阅读器状态和 Bilibili/YouTube 时间跳转。

## 发布门

- 所有离线单元、契约、安全、恢复和端到端测试通过。
- `release_check.py`、Python 编译和官方 Skill 快速校验通过。
- 本地/RSS、Bilibili、YouTube、损坏恢复、隐私导出五类前向场景通过。
- 发布 ZIP 带目录前缀、CycloneDX SBOM 和 SHA-256 sidecar。
- GitHub Actions 固定到审核过的 commit SHA；远程发布仍需用户明确授权。

## 兼容性与边界

- 核心仍不要求云 API Key；远程来源需要网络，本地无字幕转写首次使用可能需要下载模型。
- 本地 `faster-whisper` 本身不提供可靠说话人分离；v2 提供的是供应商中立的回填适配器。
- 登录、付费墙、DRM、地区限制、私人 Feed 和反爬控制不会被绕过。
- 分享完整逐字稿仍要求用户确认权利、许可或其他合法基础。
