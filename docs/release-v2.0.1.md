# Podcast Reader v2.0.1 发布说明

v2.0.1 是由一条 98 分钟 Bilibili 真链接驱动的完整性修复版本。重点不是增加表面功能，而是确保“完整读取”真的完整，并让转写质检能看见中文长段落中的重复幻觉。

## 用户最能感知的变化

- Bilibili 公共音频改为分段可恢复下载；CDN 提前结束时会继续补齐，不再把非空的截断文件当作成功。
- 下载前后均核对平台时长，已缓存的短文件或损坏文件会被识别、删除并安全重建。
- 默认保留公开 DASH 的 M4A 音频，省去一次耗时且有损的 MP3 转码；仍可显式选择 MP3、Opus 或 WAV。
- 中文、日文等无空格文本中的长串重复现在会进入质量警告，并给出具体 segment ID，方便精准复核。
- 所有中间媒体先写临时文件，只有字节数、可读性和时长均通过后才原子替换正式产物。

## 真实前向结果

- 输入：Bilibili `BV1MAut67Epv`，页面标称 5,900 秒，无公开字幕。
- 环境：无浏览器 Cookie、无云转写 API Key；本地 CPU 转写。
- 输出：5,899.520 秒完整音频、4 个可恢复块、202 个时间戳片段、9 章中文分析、11 条证据化主张、可搜索阅读器和隐私安全分享 ZIP。
- 质检：识别第 44、64 段的长重复幻觉，质量状态为 `warn/90`；报告已把对应转写风险列为限制，未把可疑文本用作逐字引文。

## 发布门

- 58 项离线测试全部通过，包含提前 EOF 恢复、时长完整性及中文段内重复回归。
- Python 编译、版本/链接/发布不变量、Skill 快速校验全部通过。
- 发布 ZIP 可确定性重建，附 CycloneDX SBOM 与 SHA-256 sidecar。

## 边界

- 不绕过登录、付费墙、DRM、地区限制或平台访问控制；仅处理公开或用户有权使用的来源。
- 本地小模型转写可零 Key 运行，但专有名词、数字和口头停顿仍应按质量报告抽检。
- 默认分享包不包含完整逐字稿；完整转录的传播仍取决于用户的权利与许可。
